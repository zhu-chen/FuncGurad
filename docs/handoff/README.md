## 阅读提示

- P1 文档的“没做什么”写着未实现 P4/P5，那是 P1 当时的状态；P4/P5 现已合入 `main`。
- P2 文档的“300 条批量流程”已在标题标注为冒烟验证（仅前 7 条），只证明批处理不中断，不代表 300 条已跑完。
- P4 文档的“没做什么”写着未提供 HTTP API / 前端、未接真实模型，那是 P4 当时的状态；P5 已补接口，P6 已接 GLM-5.3-Flash。
- P6 起默认使用真实模型，但仓库不含 key；未配置 `.env.local` 时仍回退 stub。P4/P3 文档中的检测结论仍是 stub 口径。
- P3 的检索自测里“top-3 命中 100%”是自检索上界（query 来自卡片自身的 NVD 描述），不代表泛化能力；以负例误命中与签名/标题探针为准。
- P3 最初按 0.8 口径发现 25 对 ≥0.8、15 对 0.5~0.8；同日收紧到 0.5 后，全部 178 对 ≥0.5 配对涉及的 75 条记录、另加 2 条 CVE 文本提及记录，共剔除 77 条，最终 7,497 条入索引、残余 0 对。详见 [泄漏审计报告](../p3-knowledge-leakage-audit.md) 与 [严格隔离交接](2026-11-23-p3-leakage-strict.md)。
- P1–P5 文档中的检测结论均来自 stub provider，只用于验证链路，**不代表真实检测能力**；P6 起配置 key 后使用真实模型，P7 全量评测已完成 300 条评分。
- P7 全量评测的 150 对中有 106 条样本使用合成函数文本快照（真实快照 194 条），全量结果包含这些样本；仅真实快照子集为 94 对，P-C 36 / P-V 41 / P-B 13 / P-R 4，等级 A。
- P8 只补图形输入通路，没有改提示词顺序；课程「先检索、再初判、按需读仓」的要求仍未落实，且已提交的 300 条结果对应改动前的提示词。
- 文档中的环境信息（Python 3.9.13、代理等）属于当时本机环境，代理默认值已从代码移除，需用 `FUNCGUARD_GIT_PROXY` 显式配置。
