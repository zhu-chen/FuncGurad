# 课程要求与实现对照

2026-11-24 · Codex。中国科学院大学 2026 年秋季《高级软件工程》大作业「函数漏洞检测智能体工具」要求交付一个可通过图形界面操作的 C/C++ 函数漏洞检测 Agent，并提交 300 条预测。[题目课件](../../ref/3.%20函数漏洞检测智能体工具.pptx)

| 课件页 | 课程要求 | 仓库实现与验收事项 |
|---|---|---|
| 3–5 · 知识检索 | 只用课程提供的历史 CVE 数据。历史函数可成对使用，也可利用 `cve_desc`、`commit_message`、`cwe`、`project`、`file_name` 构建或总结案例。先检索、初步分析，证据不足时才读仓库。 | 项目用知识卡片与 BM25 提供 `search_knowledge`。现有提示词优先定位和读取函数，知识检索由模型选用。验收时需核实检索发生在初步分析之前，并能在轨迹中看到对应记录。[提示词](../../backend/agent/prompts.py) · [索引与审计](../../README.md#知识库检索) |
| 4、6、8 · 单版本上下文 | 每次只给一个测试函数。漏洞版取修复提交的父提交，修复版取修复提交本身。禁止提供另一版函数、git diff 或变更信息。可按需查调用方、被调用方、全局变量、类型、宏和辅助函数。 | 快照准备按标签选择提交。配对运行逐个样本创建 `SnapshotGuard`，每次调用 Agent 都新建消息列表。复核时要检查模型实际收到的输入和工具返回。当前提示同时包含修复提交链接与带实际提交号的快照路径，应检查二者是否间接暴露版本身份。[快照管理](../../repo_service/snapshot.py) · [运行编排](../../backend/services/run_service.py) · [Agent 循环](../../backend/agent/loop.py) |
| 7 · 图形输入与报告 | 单样本输入函数代码和修复提交链接，批量入口上传 `.jsonl`。界面须支持启动检测、实时查看分析过程，并展示 idx、有无漏洞、判定理由和分析记录。分析记录包括历史案例检索和仓库读取。 | 当前页面可展示轨迹与报告。“运行单条”按现有 idx 启动，默认补齐同对样本分别推理，批量入口接收 idx 列表。直接输入函数与链接、上传文件仍待实现。验收两类轨迹时应查看该次运行的工具事件。[页面](../../web/src/App.vue) · [请求接口](../../backend/api/app.py) |
| 8–9 · 全量预测与评分 | 150 对真实漏洞函数，每对含漏洞版和修复版。提交文件 `result.jsonl` 每行仅含 `idx` 与整数 `prediction`。按 P-C 对数定级，P-R 超过 P-C 一半时降一级。 | 全量驱动写出 `full-result.jsonl`。交付时核对 300 个样本、150 个已评分配对以及失败和回退记录。课件第 9 页示例名为 `dataset/evaluate.py`，仓库驱动调用课程材料中的 `dataset/evaluation.py`。全量成绩仍待负责人确认。[评分表及提交说明](../../README.md#全量评测) · [全量驱动](../../scripts/run_full_eval.py) |
| 10 · 自主性与联网限制 | 须基于 Agent 框架自主推理与调用工具，禁止封装商业代码分析 Agent 或串行执行预设的 LLM 步骤。除按链接取得指定版本仓库外，禁止提供网络搜索。 | 当前由本地循环处理模型的工具请求与最终判定，已注册知识检索和三种只读仓库工具。LangGraph、Pi Agent、AutoGen 等是课件举例。项目采用自建循环，是否符合课程对 Agent 框架的要求仍待确认。[Agent 循环](../../backend/agent/loop.py) · [运行依赖](../../requirements.txt) |

课件列举的向量检索、GitHub API 和 Tree-sitter 均为可选实现。项目使用原生 git、文本定位和 BM25；包含度 0.5 是本项目的泄漏审计阈值。已有测试覆盖范围见[测试说明](../../tests/README.md)，全量评测进展见[任务清单](../../.agents/TODO.md)。
