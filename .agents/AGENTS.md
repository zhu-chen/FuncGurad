# .agents/ 目录说明

本目录用于存放 agent 工作流相关的文档，供项目成员和 AI agent 共同维护。

## 文件

| 文件 | 用途 |
|---|---|
| `AGENTS.md` | 本目录说明与协作约定 |
| `TODO.md` | 当前待做任务：提出人、日期、任务描述、状态 |
| `PROGRESS.md` | 已完成任务与进展记录：完成人、日期、任务说明、交代事项 |

## 任务流转（暂定）

1. 在 `TODO.md` 中新增任务，状态写“未认领（可直接开工）”。
2. 认领后注明认领人与日期。
3. 完成后把状态改为“已完成”，并在 `PROGRESS.md` 追加记录。
4. 涉及代码的改动同时更新 `README.md`、`docs/` 或交接文档中的相关说明。

> 协作流程仍在讨论中（见 `TODO.md`「确定协作流程」）。以上为当前暂定做法，正式流程确定后以最新文档为准。

## 记录约定

- 日期沿用现有写法，例如 `2026.11.23`。
- 任务标题简短明确；任务说明写改动范围与验证方式；交代事项写遗留问题、风险和注意事项。
- 不把 API key、代理地址等本机配置写入本目录或提交内容。
- 里程碑交接文档放 `docs/handoff/`，本目录只保留任务与协作记录。
